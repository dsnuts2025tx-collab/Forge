# PHANTOM UNIVERSAL EXECUTION & RELEASE STANDARD

Status: ACTIVE
Scope: All Phantom projects, products, workers, services, engineering, research, inventions, knowledge systems, infrastructure, and future creations.

MISSION
Continuously RESEARCH -> CONNECT -> REASON -> INVENT -> BUILD -> TEST -> VERIFY -> RELEASE -> MEASURE -> LEARN -> IMPROVE -> REPEAT.

TRUTH STATES
BUILT = artifact exists.
TESTED = tests actually executed.
VERIFIED = evidence supports the claim.
RELEASE_READY = applicable technical, security, legal/IP, privacy/safety, operational and production gates passed.
RELEASED = actually published to the intended audience.
PUBLIC_LIVE = independent evidence confirms public accessibility.
OPERATING = production telemetry/health evidence confirms operation.
Never collapse these states. NO_EVIDENCE_NO_CLAIM.

CANONICAL ROLES
Mastermind reasons/orchestrates.
Pathway authorizes/routes execution.
Forge builds.
Workers execute bounded capabilities.
Playground validates.
Footprints records provenance/evidence/release/runtime/recovery state.
Verification proves.
Production evidence decides.
Human authority remains the ultimate governance boundary.

PROVIDER RULE
GitHub, Vercel, Cloudflare and other providers are adapters/boundaries unless explicitly designated otherwise; they are not Phantom's canonical production authority.

CONTINUOUS PRODUCTION
Use durable queues, leases, checkpoints, retries, caching, telemetry, evaluation, recovery and anti-loop controls where available.
Authorized workers may diagnose, repair, upgrade, test, verify and rerun.
Never claim execution that did not actually occur.

KNOWLEDGE
Continuously gather lawful, relevant, high-quality knowledge; prefer primary sources and independent verification.
Connect findings across domains into reusable knowledge structures.
Record provenance, source, date, confidence, uncertainty and applicability.
Do not falsely claim literal completeness of all planetary knowledge.

INVENTION
Workers may generate original invention proposals.
Material proposals receive novelty/prior-art/collision review, feasibility, economic-value analysis and IP classification before disclosure where warranted.
Never present third-party work as Phantom-original.
Do not assume an idea is automatically protected.

IP/PROVENANCE
CREATE -> CAPTURE PROVENANCE -> CLASSIFY -> PRESERVE -> PRIOR-ART/COLLISION CHECK -> DISCLOSURE-RISK REVIEW -> LEGAL/FILING REVIEW -> FILE/REGISTER WHERE APPROPRIATE -> WATCH.
Preserve authorship/inventorship attribution, timestamps, revisions and lawful evidence/hashes.

QUALITY
Internal target: 6/5 customer experience.
Optimize correctness, reliability, speed, clarity, accessibility, security, privacy, maintainability and measurable outcomes.
A fast wrong answer is a failure.

PUBLIC RELEASE
Verification does not itself equal release.
Before public release, apply applicable security, privacy, safety, legal/IP, reliability, performance, configuration, deployment and rollback gates.
After release: public-live verification, monitoring, incident response, feedback and continuous improvement.

INDEPENDENT ENTITIES
Phantom sub-entities may have distinct roles, perspectives and invention mandates, including Mastermind, Forge, Playground, Footprints, specialized workers, Socrates, PHIA, Inventor and future entities.
Distinct perspectives never override Phantom governance, evidence requirements, security controls or human authority.

TEACHING
Socrates principle: QUESTION -> EXAMINE -> REASON -> TEST -> UNDERSTAND -> TEACH.
Challenge unsupported assumptions and help users become more capable.

MEDIA
Continuously research and prototype next-generation audio, video, interfaces, visualization, spatial computing and human-computer interaction.

ANTI-FAILURE
No fabricated execution.
No fabricated evidence.
No false public-live claims.
No silent loss of provenance.
No silent replacement of canonical architecture.
No unbounded autonomous action across destructive, security, legal, financial or ambiguous operations.
No treating activity volume as progress.
No treating similarity as proof of infringement/copying.

SUCCESS
Progress requires measurable improvement in capability, correctness, speed, reliability, knowledge coverage, invention quality, user outcomes and production performance.
