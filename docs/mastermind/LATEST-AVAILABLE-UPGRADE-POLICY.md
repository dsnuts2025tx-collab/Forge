# Mastermind v2.1 — Latest-Available Upgrade & Refresh Policy

Status: LOCKED CANONICAL
Effective: 2026-08-25

## Objective
Keep Mastermind, Forge, and their capabilities current by evaluating the latest legitimately available improvements at each upgrade cycle, while preserving compatibility, security, truthfulness, customer trust, and architectural control.

## Scope
Evaluate upgrades across models, agent frameworks, multi-agent protocols, memory, orchestration, communications, CRM/business operations, carrier/eSIM interfaces, satellite/NTN interfaces, security, observability, testing, deployment, infrastructure, cost controls, recovery, data systems, and customer experience.

## Latest-available rule
At each planned refresh, research the current available release/capability for each relevant dependency or technology. Prefer the latest stable, supported, production-suitable version when it materially improves the system. Do not blindly adopt prerelease, experimental, incompatible, unavailable, or unnecessary changes.

## Selection criteria
A candidate upgrade is evaluated for:
- security and privacy improvement;
- reliability and resilience;
- performance and latency;
- correctness and verification;
- capability coverage;
- interoperability and standards compliance;
- cost and resource efficiency;
- operational maturity and support;
- customer benefit;
- portability and first-party control;
- migration complexity and rollback safety.

## Current 2026 intelligence inputs
The architecture should account for the industry move toward interconnected autonomous agents, persistent context, agent orchestration, agent-to-agent protocols, dynamic AI governance, and unified conversation infrastructure. Current market evidence includes Google Gemini Enterprise for agent development/orchestration/governance, ServiceNow agent-to-agent 1.1 and semantic-memory updates, Twilio Conversation Memory/Orchestrator/Intelligence, Salesforce agentic enterprise capabilities, and current AI gateway governance patterns. These are competitive inputs, not mandatory dependencies.

Direct-to-device satellite/NTN capabilities are also rapidly advancing. Current 2026 industry evidence includes ITU D2D convergence work, standards-based 5G NR NTN, and demonstrations of D2D SMS/SOS on standard Android devices. These are evaluated as legitimate external-boundary integration opportunities, not proof that Phantom has live satellite service.

## Integrate / Create / Through
For each candidate:
1. INTEGRATE when a legitimate existing capability satisfies the requirement.
2. CREATE when a real gap remains or first-party ownership materially improves control, security, economics, portability, reliability, or verification.
3. GO THROUGH when infrastructure must remain external, using authorized interfaces and provider agreements.
4. COMBINE approaches when that yields the strongest verified result.

## Promotion lifecycle
DISCOVER -> CLASSIFY -> EVIDENCE -> GAP ASSESSMENT -> SECURITY/COMPATIBILITY REVIEW -> COST/OPERABILITY REVIEW -> TEST -> INDEPENDENT VERIFY -> MASTER APPROVAL -> IMPLEMENT -> DEPLOY -> OBSERVE -> RECONCILE.

## Production truth
Latest version does not mean production-ready. Production promotion still requires the canonical truth-state lifecycle and real-world evidence. External carrier/satellite capabilities require legitimate authorization, credentials, compatible hardware/interfaces, provisioning, observed behavior, and verification.

## Daily/continuous refresh
Mastermind may perform recurring refresh work within configured automation and authorization limits. It should detect stale dependencies, security issues, material market changes, and useful upgrades. Safe changes may proceed through the normal gated pipeline; consequential production changes retain appropriate testing, verification, auditability, authorization, monitoring, and rollback controls.

## Anti-regression rule
An upgrade is not accepted if it improves one dimension while causing an unacceptable regression in security, privacy, reliability, compatibility, customer experience, cost, or truthfulness. Preserve rollback paths and compare before/after measurements.

## Permanent principle
Always seek the best legitimately available technology at the time of the decision—not simply the newest technology by date. Mastermind optimizes for verified value, not version numbers.
