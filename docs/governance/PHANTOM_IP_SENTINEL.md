# Phantom Native IP Sentinel
First-party provenance and evidence system for Phantom.

It does not accuse. It observes, fingerprints, preserves, compares, and classifies evidence.

## Commands
- `phantom-ip-sentinel.sh` — baseline and repeatable integrity scan.
- `phantom-ip-observe.sh SOURCE EVIDENCE_FILE` — ingest an observed external artifact supplied to Phantom.
- Evidence states: OBSERVED, POSSIBLE_OVERLAP, STRONG_INDICATION, CONFIRMED_EVIDENCE, FALSE_POSITIVE, RESOLVED.
- No state constitutes a legal infringement determination.

## Authority
Phantom is canonical. Third-party services are not production authority.
