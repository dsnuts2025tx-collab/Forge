# Competitive Verification Matrix

## Purpose
Prevent unsupported claims that Phantom is ahead. Compare implemented evidence against the current competitive floor and require proof for every claim.

## States
- GAP: capability absent
- PLANNED: design exists
- BUILT: code exists
- TESTED: automated tests pass
- VERIFIED: independent evidence exists
- DEPLOYED: running in target environment
- PRODUCTION: real-world acceptance passed

## Required evidence
For each capability record:
- capability ID
- implementation path
- tests
- workflow/deployment run
- security review where consequential
- external integration evidence where applicable
- production acceptance evidence
- current state

## Phone Service acceptance
The phone service cannot reach PRODUCTION until evidence exists for:
- persistent $0 entitlement;
- authenticated customer identity;
- Wi-Fi disabled;
- real cellular registration;
- real voice/SMS/data where promised;
- legitimate provider authorization;
- usage/cost reconciliation;
- funding coverage;
- compatible satellite registration where supported;
- satellite fallback test where supported;
- verification receipt generated from observed evidence;
- recovery from a failed path.

## Competitive claim rule
Do not state "ahead of" any competitor unless this matrix contains VERIFIED/PRODUCTION evidence for the compared capability and a documented differentiator.
