## Customer Launch Objective

The product must progress toward:

Discover → Visit → Understand → Experience → Create account → Receive value → Choose membership → Pay through lawful payment rails → Receive entitlement → Use product → Return → Retain.

## Zero Orphan Problems

When a worker discovers a problem:

- Resolve it if within authority.
- Coordinate with the responsible worker if cross-domain.
- Create a durable record if tracking is required.
- Verify the resolution.
- Search for related failures before closing the work.

No worker should knowingly leave a discovered production-blocking defect without a clear owner or escalation path.

Do not import the old Insight architecture wholesale.

Do not make a vendor a foundational dependency merely because it is convenient.

External services may be used only where genuinely necessary and must be isolated behind the Phantom External Boundary Layer with documented purpose, permissions, data flow, failure handling, and replacement strategy.
